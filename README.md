# Bunpuku おみくじ（Web 版）

こするとおみくじ、振るとやり直し。2011 年の iPhone アプリ「Bunpuku」を Web アプリとしてリマスターしたもの。

iPhone では Safari で開き、「共有 › ホーム画面に追加」すると全画面で遊べます。
